# Code of Conduct

All participants in the BAOBAB project are expected to engage respectfully, constructively, and professionally.

## Community Expectations

- Be kind and considerate in discussions.
- Assume good intent and provide helpful feedback.
- Keep technical discussions focused on the project and its goals.
- Report inappropriate behavior through the project’s established channels.
