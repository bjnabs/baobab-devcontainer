# Glossary

- **Development container**: A reproducible environment packaged with the tools and runtimes required for a project.
- **Deterministic build**: A build that produces the same result for the same inputs.
- **Toolchain**: The combined set of compilers, runtimes, and utilities used for development and delivery.
