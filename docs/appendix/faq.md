# Frequently Asked Questions

## What is BAOBAB?

BAOBAB is an enterprise-grade development container designed to make local and cloud development environments consistent and reproducible.

## Why use a development container?

It removes environment drift, standardizes software versions, and helps teams work from the same toolchain.

## Where should I start?

Begin with the usage guide for your preferred workflow, then consult the reference pages for specifics.
